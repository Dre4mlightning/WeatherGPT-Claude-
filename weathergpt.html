About this prototype

WeatherGPT is a SIH2026 concept build for PS SIH26068 (Ministry of Earth Sciences). This demo runs on open public weather data to show the conversational layer end-to-end.

A production deployment would replace this data layer with live IMD, Mausam, Meghdoot and Damini feeds, plus an LLM grounded via retrieval so every figure it states is sourced and verifiable.
